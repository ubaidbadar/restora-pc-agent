- Committers and reviewers: Ubaid Badar.
- Approvers: Ubaid Badar.

## What is signed

- Only GitHub Actions release builds built from the public repository are submitted for signing.
- Only the project's own binaries are signed. No upstream binaries are signed with this subscription.
- Every release needs manual approval for signing.

## Certificates

Certificates are issued in SignPath Foundation's name and may be paused, terminated, or revoked if the SignPath Foundation terms are violated.
